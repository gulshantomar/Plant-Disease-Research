# Plant Disease Web App 1. Copy this `webapp` folder into the ROOT of your project (next to `Mobilenetv2/`, `DenseNet121/` ...). 2. `pip install -r requirements.txt` 3. `python app.py` -> open http://localhost:5000 Models are auto-detected from `/models/.keras`. InceptionV3 and ResNet50V2 show as disabled until you add `InceptionV3/models/inceptionv3.keras` and `resnet50v2/models/resnet50v2.keras` (they were not in the GitHub zip).
